# חיבור הציונים ל-Google Sheet

האתר עצמו נשאר קובץ אחד (`index.html`). השמות, הקודים, הציונים והתשובות נשמרים בגיליון, דרך סקריפט של גוגל. בדפדפן לא נשמרת היסטוריה. אם אין אינטרנט בסוף מבחן, הציון ממתין במכשיר ונשלח בכניסה הבאה, ואז נמחק מהמכשיר.

השאלות שכבר בתוך `index.html` לא נמחקו. הן גם בקובץ `apps-script/questions.json`, כדי שאפשר לייבא אותן לגיליון בלחיצה אחת.

## למה הקובץ questions.json

הדרך הפשוטה: אחרי שהקובץ הזה נמצא בגיטהאב, בסקריפט מריצים פעם אחת את `importQuestions`. הפונקציה מורידה את `questions.json` וממלאת את לשונית השאלות. לא צריך להדביק מאות שאלות ביד.

בגיליון יש גם שלוש עמודות נוספות, מעבר לעמודות שביקשת: `q_id`, `kind`, `fig_json`. הן שומרות את הציורים ואת מספר השאלה המקורי, כדי שמבחן צורות לא יישבר אחרי הייבוא. שאלות התרגול החופשי (שלא שייכות למבחן מלא) נכנסות עם `exam_id` בשם `practice`, והאתר לא מציג אותן כמבחן חמישי.

## 1. גיליון חדש

1. נכנסים ל-[Google Drive](https://drive.google.com).
2. נכנסים לתיקייה **הכנה למבחן קרני - מיכל**. אם אין תיקייה כזאת, יוצרים אותה.
3. חדש → Google Sheets.
4. קוראים לגיליון **מבחני קרני - נתונים**.

## 2. הדבקת הסקריפט

1. בתוך הגיליון: **תוספים** → **Apps Script**.
2. מוחקים את מה שמופיע בקובץ `Code.gs` בעורך.
3. מעתיקים את כל התוכן של `apps-script/Code.gs` מהמאגר, ומדביקים במקום.
4. שומרים (Ctrl+S).

## 3. פריסה

1. למעלה: **פריסה** → **פריסה חדשה**.
2. סוג: **אפליקציית אינטרנט**.
3. הפעלה בתור: **אני**.
4. למי יש גישה: **כל אחד**.
5. **פריסה**. מאשרים את ההרשאות (גיליון, וגישה לכתובת חיצונית כדי לייבא שאלות).
6. מעתיקים את כתובת ה-Web App. היא נגמרת ב-`/exec`.

## 4. כתובת הסקריפט באתר

בקובץ `index.html`, בשורה שמתחילה ב-`const SCRIPT_URL`, שמים את הכתובת בין המרכאות:

```js
const SCRIPT_URL = "https://script.google.com/macros/s/....../exec";
```

שומרים, ודוחפים ל-`main` (`git push`). בלי זה האתר עדיין עובד מהשאלות שבקובץ, אבל הציונים רק ממתינים במכשיר.

## 5. ייבוא השאלות, פעם אחת

1. בעורך של Apps Script בוחרים למעלה את הפונקציה `importQuestions`.
2. לוחצים **הרצה**.
3. בגיליון אמורות להופיע הלשוניות `questions`, `users`, `attempts`, ובלשונית `questions` 692 שורות (4 המבחנים המלאים ועוד שאלות תרגול).

אפשר להוסיף אחר כך שאלות חדשות ידנית בגיליון. שורה עם `exam_id` חדש תופיע כמבחן נוסף. `exam_id` שכבר קיים (1 עד 4) מחליף את המבחן שבקובץ. אם הגיליון לא זמין, האתר ממשיך עם השאלות שבקובץ ומראה הודעה קטנה.

## כניסה

במסך הפתיחה: שם וקוד בן 4 ספרות. **כניסה** למשתמש קיים, **משתמש חדש** לפעם הראשונה. כל אחת רואה רק את הציונים שלה. **החלף משתמש** בראש הדף.

היסטוריה ישנה שנשמרה בדפדפן (המפתח הישן של מיכל) עולה פעם אחת למשתמש **מיכל** ברגע שיש `SCRIPT_URL` והדף נפתח, ואז נמחקת מהדפדפן. צריך לפתוח את האתר פעם אחת, אחרי העדכון, במחשב שבו נשמרו הציונים הישנים.
